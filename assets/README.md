# Recursos compartidos

Conservar los logos originales suministrados, sus proporciones y variantes. Utilizar DejaVu Sans normal y negrita con la licencia incluida. El CSS conserva la estructura visual del paquete de referencia y agrega selector de lenguaje y controles accesibles.

Cada segmento incluye una síntesis técnica exacta en SVG y PNG. La versión vectorial se muestra en el material y la versión PNG permite compartirla o proyectarla. La tipografía del Markdown depende del visor; HTML y PPTX utilizan las fuentes indicadas.
