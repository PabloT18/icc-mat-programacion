PL3.3 · Informe de mediciones y registros

Objetivos prácticos

  • Transformar matrices mediante funciones y ciclos anidados.
  • Relacionar filas con registros y validar dimensiones.

Contexto

Procesar una matriz rectangular de mediciones y una lista de tuplas (codigo, nombre) para identificar sus filas. Clasificar mediciones, resumir cada fila y generar un informe sin modificar las entradas.

Recursos y tiempo

Computador, Python, editor, terminal y Git. Utilizar bibliotecas estándar. Tiempo estimado docente: 6 horas. Esta estimación no modifica las horas oficiales del programa.

Instrucciones y restricciones

  • Exigir una tupla identificadora por fila.
  • Clasificar <10 como BAJA, de 10 a 20 inclusive como NORMAL y >20 como ALTA.
  • Retornar una matriz nueva de etiquetas.
  • Mostrar código, nombre y etiquetas separadas por |.
  • Informar cantidad de ALTA por fila; no confundir mayoría con existencia.
  • Aceptar matriz vacía con lista de identificadores vacía; rechazar irregularidad y filas sin mediciones.

Actividades por fases

1. Modelo

Definir esquemas de matriz y registros, validación y contratos.

Registrar un commit funcional: feat(pl3.3): fase-1-descripcion. Sustituir descripción por el cambio realizado y conservar el hash real.

2. Transformación

Crear filas nuevas y comprobar que las originales permanecen iguales.

Registrar un commit funcional: feat(pl3.3): fase-2-descripcion. Sustituir descripción por el cambio realizado y conservar el hash real.

3. Resumen

Contar ALTA por fila y asociar la tupla correspondiente.

Registrar un commit funcional: feat(pl3.3): fase-3-descripcion. Sustituir descripción por el cambio realizado y conservar el hash real.

4. Integración

Presentar el informe, comprobar límites y defender una modificación de umbrales.

Registrar un commit funcional: feat(pl3.3): fase-4-descripcion. Sustituir descripción por el cambio realizado y conservar el hash real.
