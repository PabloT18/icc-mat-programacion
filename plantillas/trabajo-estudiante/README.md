# Actividades de Programación

Completar autor y grupo en la copia personal. Crear una carpeta por actividad dentro de `actividades/` y su evidencia en `evidencias/`. Usar una versión por PC y Python para PL. No existe proyecto acumulativo.

Crear los fuentes de cada actividad y explicar cómo ejecutarlos desde su carpeta. Incluir casos propios. Mantener código de cálculo separado de presentación cuando el tema ya haya introducido funciones. Registrar un commit por cambio funcional.
