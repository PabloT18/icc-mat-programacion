Ejecutar ejemplos

Usar los lanzadores desde la raíz: python3 demostraciones/python/ejecutar.py 3.09 o python3 demostraciones/java/ejecutar.py 3.09. Sustituir el código por cualquier segmento del catálogo. Los fuentes viven en ejemplos/ de cada versión; no mantener copias duplicadas.

El lanzador Python utiliza el intérprete con el que se inicia. El lanzador Java requiere javac y java en PATH y compila en una carpeta temporal que se elimina al finalizar. Los ejemplos que necesitan entrada utilizan su archivo entrada.txt. Los ejemplos de archivos trabajan en carpetas temporales.
