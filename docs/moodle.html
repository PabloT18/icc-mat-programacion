Bancos Moodle XML

Cada segmento contiene moodle/banco-python.xml, con diez preguntas: cuatro conceptuales y seis de trazas. Los bancos son material docente y no se enlazan desde las lecturas de estudiantes. Las categorías siguen unidad, segmento y subcategorías Conceptos y Python - trazas.

Importación

Abrir el banco de preguntas del curso, seleccionar Importar y formato Moodle XML, elegir el archivo correspondiente y conservar las categorías incluidas si se desea esa organización. Revisar los nombres de curso y categorías antes de confirmar en la instalación institucional.

Cada pregunta de opción múltiple tiene una respuesta correcta, fracción 100 y distractores con fracción 0. El XML incluye retroalimentación y calificación base 1. Las trazas usan datos concretos; no son entregas resueltas de PC o PL.

Validar estructura y respuestas no equivale a importar en una instancia real de Moodle. La comprobación local registra XML bien formado, categorías, número de preguntas y fracciones. Revisar una importación de prueba en el Moodle de destino antes de usar los bancos en una evaluación.
